# Financial-News · 财经资讯聚合平台（原型）

面向 **A股个人投资者** 的金融资讯聚合平台原型，对应《项目需求.md》（需求规格说明书 v1.1）。

## 目录结构

```
├── 项目需求.md          # 需求规格说明书 v1.1（财经专家/架构师/产品经理视角）
├── index.html           # 本地预览入口（自动跳转 /web/index.html）
└── web/                 # 前端原型（纯静态，可直接双击打开）
    ├── index.html       # 页面骨架
    ├── styles.css       # 样式（移动端优先、响应式）
    ├── data.js          # 演示数据（模拟资讯/公告/传闻/行情，非真实信息）
    └── app.js           # 交互逻辑
```

## 功能（对应需求编号）

- 实时信息流 + 类型（快讯/深度/公告/传闻）、市场、行业筛选 —— FR-01/02
- 全文搜索（近 7 日）—— FR-03
- 个股主页聚合（公告/新闻/传闻/情感分布）—— FR-04
- 自选股订阅（localStorage）—— FR-05
- 重要消息甄别与热点榜（实时/当日/近7日）—— FR-06/07
- 传闻管理："未经证实"标识、默认不推送、澄清公告对照 —— FR-08/COM-4
- 企业微信推送模拟（送达/去重合并/频控）—— FR-09
- 行情联动：涨停/异动标注、延时行情模拟刷新 —— FR-17/DP-7/DR-12
- 数据保留策略展示（近 7 日）—— R-1

## 运行

方式一（本地预览，任选其一）：

```bash
# 进入 web 目录后启动静态服务
cd web && python -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/
```

方式二：直接双击 `web/index.html`（纯静态，无需服务器）。

> ⚠️ **原型演示模式**：页面内全部资讯、行情与推送均为**模拟数据**，非真实市场信息，不构成任何投资建议。真实数据源接入（财联社/巨潮等）、NLP 去重/情感/分类、真实企微发送等后端能力见《项目需求.md》"待立项"部分。
